# FierceSloth — Strict Mode

**Tech:** Firebase, Husky, Render, SCSS, Supabase, TypeScript, Vitest

## Context (read before the call)
- Архитектурный лидер команды: спроектировал структуру проекта с нуля, написал CONTRIBUTING.md, GIT_FLOW.md и Component Guidelines, создал VS Code сниппеты для команды.
- Построил CodeEngineService — песочницу для выполнения пользовательского кода через WebWorker, Blob URL, monkey-patched console.log и таймаут-защиту от бесконечных циклов; движок используется минимум в трёх виджетах через реюзабельный ExecutionController.
- Столкнулся с парадоксом UX: WebWorker работал слишком быстро — вывод появлялся мгновенно, и интерфейс казался сломанным. Решение — осознанная искусственная задержка (паттерн Labor Illusion).
- Инициировал командный переход с SCSS-переменных на CSS-переменные, аргументируя глобальной доступностью и возможностью переопределения в медиа-запросах — решение принято командой.
- Исследовал Monaco vs CodeMirror, выбрал CodeMirror по соображениям размера бандла; сформулировал архитектурный принцип 'страница только возвращает элементы, роутер владеет DOM-вставкой', убрав singleton layout-паттерн.
- Ведёт активное ревью всех крупных PR команды; в случаях, когда логика верна, а стили расходятся — правит стили сам, а не пишет комментарии.
