# coicoin — Strict Mode

**Tech:** React, Redux, Render, SCSS, Supabase, Vite

## Context (read before the call)
- Взял на себя реализацию кастомного SPA-роутера с нуля (HistoryAPI, params, queries, secured pages, replaceState, navigate(-1)) — без React Router, несмотря на использование React.
- Потратил несколько дней по 8 часов на роутер; воссоздал аналоги useNavigate/useParams с Emitter под капотом, разобравшись, как React Router работает изнутри.
- Поймал и починил реальный баг: location.pathname не содержит query string — диагностировал и исправил через конкатенацию pathname + location.search.
- Столкнулся с ограничением SCSS: var() не вычисляется на этапе компиляции как аргумент миксина, пришлось отказаться от font-миксина.
- Самостоятельно мигрировал проект с @import на @use, разобравшись с устареванием старого синтаксиса Sass.
- Участвовал в командном обсуждении SCSS-переменных vs CSS-переменных и конфигурации Vite — пришли к решению через preprocessorOptions.
- Последние задачи: Quiz page с сохранением прогресса в Supabase, UI со звёздочками; работает над True/False страницей.
