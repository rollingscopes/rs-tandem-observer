Минуты 2–3 — Кнопка
Диана

Первый — кнопка. Звучит просто, да? Я тоже так думала.

Открывает VS Code. 45 строк шаблона.

button.component.html
@if (href() && !disabled()) { <a [href]="href()" [attr.aria-label]="displayAriaLabel()"> } @else if (link() && !disabled()) { <a [routerLink]="link()"> } @else { <button [disabled]="disabled()" [attr.aria-busy]="isLoading ? 'true' : null"> }
Диана

Три ветки. Внешняя ссылка — <a href>. Внутренний роут — <a routerLink>. Всё остальное — <button>.

Обратите внимание: && !disabled(). Если кнопка disabled — всегда рендерится <button>.

Потому что <a> нельзя нормально задизейблить. Я потратила два вечера. Сначала pointer-events: none — пропадает курсор. Потом aria-disabled плюс preventDefault(). Вроде ок. Почти закоммитила. И тут...

Минута 4 — Решение
Диана

Решение — не рендерить <a> вообще. Disabled? Значит <button disabled>. Точка. Не CSS-хак. Просто не рендери то, что не должно быть кликабельным.

Диана

Страница профиля. Под капотом — четыре сервиса. Тут я впервые столкнулась с паттерном Facade.

profile.facade.ts
private authService = inject(AuthService); private profilesService = inject(ProfilesService); private authStore = inject(AuthStore); private modalService = inject(ModalService);
Диана

Без Facade компонент знает про все четыре, вызывает в правильном порядке, обрабатывает ошибки каждого. Я поняла это, когда мой компонент разросся до 200 строк и я перестала понимать свой код.

Минуты 9–10 — RxJS
profile.facade.ts — constructor
toObservable(this.user).pipe( filter(user => !!user), take(1), switchMap(() => forkJoin([ this.profilesService.getProfile('me'), timer(DELAY_MS) // ← 300ms ]) ), )
Степан

А timer(DELAY_MS) — это зачем?

Диана

Если бэкенд ответит за 50 мс, лоадер мелькнёт — появится и исчезнет, как баг. forkJoin с timer(300) гарантирует минимум 300 мс. Маленькая штука, но UX заметно лучше.

scroll-spy.service.ts
this.observer = new IntersectionObserver( (entries) => { if (this.isAnchorLocked) return; entries.forEach(entry => { if (entry.isIntersecting) this.activeAnchor.set(entry.target.id); }); }, { rootMargin: '-80% 0px -80% 0px' } ); // при клике по навигации: setAnchorManually(id: string) { this.isAnchorLocked = true; this.activeAnchor.set(id); window.addEventListener('scrollend', () => { this.isAnchorLocked = false; }); }
